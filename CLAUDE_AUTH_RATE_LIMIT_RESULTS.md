# CLAUDE_AUTH_RATE_LIMIT_RESULTS

> Ответ на `CLAUDE_AUTH_RATE_LIMIT_TASK.md` (ветка `codex/auth-abuse-protection`). Claude, 2026-07-07.
> Backend и миграции не тронуты. Все правки — frontend, в рабочем дереве текущей ветки.

## Что сделано

### `сайт и приложение/app.html` (+ iOS-зеркало `maya-ios/www/index.html`, md5 идентичен)

1. **`localBookingFetch`** — из не-ok ответа извлекается `error.retry_after_seconds`, фолбэк заголовок `Retry-After` → `err.retryAfterSeconds` (сек, ceil).
2. **`authCodeText`** — код `auth_rate_limited` → «Слишком много попыток. Подождите N с и попробуйте снова.»
3. **Телефон / start**: на `429 auth_rate_limited` серверное значение пишется в существующий SMS-таймер `authResendAt` (п.5 задания); кнопка «Получить код» и линк «Отправить ещё раз» блокируются с live-countdown.
4. **Телефон / verify**: отдельный лок `authLocks.verify` — кнопка «Войти» → «Подождите · N с», после истечения снова активна.
5. **Соц-вход (Яндекс/Telegram) / start**: лок `authLocks.social` — обе кнопки дизейблятся с countdown; блокируется только соц-действие, телефонный путь доступен.
6. **Рестор сессии (refresh-аналог, `GET /me`)**: при `auth_rate_limited` токены **не** очищаются; повтор по серверному времени (`setTimeout`, пейсинг серверный, максимум 3 попытки — не цикл); если лимит не отпустил — экран входа, токен остаётся до следующего запуска. Прочие ошибки — прежнее поведение (clear + anon).
7. Тикер countdown расширен (был только на стадии `code`) — работает на всех auth-стадиях, самоостанавливается, переживает re-render.

### `сайт и приложение/maya-start.html` (trial signup)
`429 auth_rate_limited` → сообщение + кнопка «Создать салон бесплатно» превращается в «Подождите · N с» (локальный тикер), после истечения активна.

### `сайт и приложение/maya-admin.html` (password login)
`api()` прокидывает `err.code` + `err.retryAfterSeconds`; `doLogin` на `auth_rate_limited` блокирует кнопку «Войти» с countdown (Enter в полях тоже гейтится), после истечения активна.

### `сайт и приложение/oauth-callback.html` (`/auth/oauth/*/complete`)
`429 auth_rate_limited` → человеческое сообщение с live-countdown в тексте; авто-ретрая нет; кнопка «Вернуться ко входу» всегда активна.

## Гарантии из задания

- Авто retry-loop нигде не добавлен (единственный отложенный повтор — рестор сессии, серверный пейсинг, cap 3).
- Технический JSON пользователю не показывается.
- Блокируется только повторяемое действие, не всё приложение.
- Остальные экраны/дизайн не менялись.
