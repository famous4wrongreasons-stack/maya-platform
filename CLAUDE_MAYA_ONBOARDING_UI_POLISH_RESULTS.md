## A. Короткий онбординг в обычном чате MAYA

1. Приветствие ровно: «Здравствуйте! Я Майя, помогу настроить ваш бизнес. Вы работаете на себя или у вас бизнес?».
2. До черновика — только два чипа из `onboarding_flow.work_modes`: «Работаю на себя» → шлёт `Я работаю на себя`, «У меня бизнес» → `У меня бизнес`. Старый «широкий» выбор шаблонов на первом экране убран (профессии приходят из backend `quick_replies`/`categories`).
3. `quick_replies` теперь **выполняют действие**: `action=confirm`/`edit` → сразу открывают редактируемую карточку (`onbToConfirm`); `action=focus` → фокус в композер (клавиатура не падает, пустое сообщение не шлётся); иначе `onbSend(message, templateId)`. Двойные тапы блокируются (`disabled` при `onbBusy`), нажатое состояние — только на время запроса.
4. Свой чип «К подтверждению» больше **не** дублируется, если backend уже прислал «Можем начинать»/«Отредактировать данные».
5. Клавиатура: чат живёт внутри `visualViewport`, композер стоит над клавиатурой (`footRef` bottom:0), автоскролл вниз — только после реальной отправки (`forceChatBottomRef`), при наборе/чтении старых сообщений позиция не дёргается — существующий контур уже соответствует требованию, ломать его не стал.

## B. Карточка подтверждения

1. Название необязательно при `businessNameDeferred`: плейсхолдер и подпись «Без названия — можно добавить позже», локальная валидация не падает, пустое имя **не уходит** в confirm-JSON (`delete body.businessName`).
2. Услуги можно отложить (`servicesDeferred`) — валидация не требует их. Цена `0`/пусто → подпись «Цена не указана» (нигде нет «Бесплатно» — проверено grep).
3. Строка «Сфера / профессия» показывает реальную метку из `categories` по `categoryId` (`onbCategoryLabel`), а не только легаси-шаблон.
4. Человекочитаемо: «Формат работы» → «Работаю один» / «Команда: N специалистов» (не голая 1); «Расписание» → «Внутренний календарь MAYA» / «CRM». График/услуги/контакты остаются редактируемыми.
5. Телефон: по умолчанию `+7`, но международный поддержан — компактный селектор кода страны (`RU/KZ +7`, BY/UA/GE/UZ/KG/US/UK/DE/AE) + «Другой код» с ручным вводом. Валидный `+`-номер (10–15 цифр) сохраняется как есть; не-российский код **не** переписывается на `+7`.
6. «Можем начинать» открывает карточку на ревью (бизнес ещё не создаётся) → создание по «Создать бизнес»; «Отредактировать данные» открывает ту же карточку без создания тенанта.

## C. Визуальные фиксы кабинета

1. Табы: класс `.me-noscroll` (`::-webkit-scrollbar{display:none}` + `scrollbar-width:none`) + запас снизу (`paddingBottom:10`, `margin-bottom:18`) — линия скроллбара не касается пилюль; горизонтальный свайп и выделение активного таба сохранены.
2. Загруженный логотип: во **всех** трёх местах (`LogoM`, бар-лого, splash) `filter: brightness(0)` больше не применяется к `window.__ME_LOGO` — только к монохромному дефолтному знаку. `object-fit: contain`, `max-width/height:100%`, без обрезки, без круга/фона. Чёрно-фоновая картинка снова показывает белую M (проверено: computed `filter: none`).
3. Плитка «Специалисты»: круг/рамку вокруг знака убрал; рендерю самостоятельный знак «Семя жизни» с плавным вращением `meSeedSpin 16s linear infinite` и `@media (prefers-reduced-motion:reduce){animation:none}`.
4. Фото solo-мастера: при ровно одном специалисте в разделе «Расписание» — блок «Загрузить фото мастера» → `POST /internal-calendar/providers/:id/avatar` (multipart `avatar`, PNG/JPEG/WEBP/GIF ≤2 МБ), прогресс «Загружаем…» + дружелюбные ошибки типа/размера, после успеха `loadMyCal()` (refresh setup), рендер `object-fit: cover`, фолбэк — знак «Семя жизни».
5. Палитра — только ЧБ/нейтральные серые; бронзу/золото не вводил.

## D. Безопасный возврат в основной воркспейс

Owner-only строка в меню профиля «Вернуться в Мужскую Эстетику» → `window.__meReturnToLegacyWorkspace()`. Гейт: `_pmAuthed && window.__ME_SAAS_CTX && typeof window.__meReturnToLegacyWorkspace === 'function'` — то есть видна только в тест-тенанте и только там, где функция определена (iOS-сборка владельца); публичные/веб-пользователи её не видят. Сохранённые SaaS-сессии и тестовые бизнесы не трогаются (функция лишь переключает воркспейс).

## Честные заметки

- Оба приёмочных потока пройдены: solo-барбер без названия (создание тенанта подтверждено) и бизнес-путь с категориями (переход к выбору бизнес-категории/количества специалистов). До-конца создание бизнес-тенанта с 3 специалистами отдельным live-прогоном не гонял, чтобы не плодить тестовые тенанты — контракт `providerCount` и человекочитаемая строка «Команда: N специалистов» проверены в карточке.
