# Единое нижнее меню (persistent bottom nav) — задание себе на новую сессию

> Причина: анимация индикатора (референс @illiyinstudio) НЕВОЗМОЖНА, пока меню
> пересоздаётся на каждом экране. Подтверждено записью экрана Стаса 29.07:
> индикатор скачет, на части экранов отсутствует. Косметикой не чинится.

## Цель
Одно меню, живущее НАД экранами и НЕ пересоздающееся при навигации. Экраны
меняются под ним. Тогда индикатор течёт непрерывно, как в референсе.

## Сейчас (три независимых реализации — в этом корень)
1. `AuroraTab` (app.html ~2464) — компонент бара. Рендерится:
   - через `Shell` (~2416) с `active: tab.active` — экраны клиента;
   - обёртка ~3359 (`clientTabItems()`);
   - глобальный `gTab` (~30794) — **шлёт `active: 99`** (нет активной вкладки)
     для клиента; для персонала `gStaffActive[screen]`. Показывается только для
     `noOwnTab = ['shop','invite','settings','book','tips','panel']`.
2. **Своё меню у чата** — внутри `AChat` (~15245, в iOS ~15753): собственная
   разметка из `CLIENT_TABS`/`STAFF_TABS`, `var on = i2 === 1`, своя логика
   `chatNavShrunk`/`keyboardEngaged` (в iOS ещё absolute-позиционирование).
3. Экран расписания/журнала и др. — свои back-стрелки, без бара.

## Что делать
1. Рендерить **один** `AuroraTab` в корне приложения (там же, где `gTab`), всегда,
   независимо от экрана. Убрать рендер бара из `Shell`, из обёртки ~3359 и из `AChat`.
2. Активную вкладку вычислять из текущего `screen` одной картой:
   `home→0, chat→1, записи→2, профиль/cabinet→3` (клиент) и аналогично для персонала.
   Экраны без вкладки (shop/invite/settings/book/tips/panel/schedule/journal) —
   не `99`, а «меню скрыто» (`bottomNavHidden`), чтобы не было кадров без индикатора.
3. Сохранить поведение чата: скрытие бара при клавиатуре (`keyboardEngaged`) и
   `chatNavShrunk` — вынести в тот же единый бар через глобальные флаги/события
   (`me-bottom-nav-visibility` уже есть — см. `setBottomNavHidden`).
4. Индикатор: код уже написан и выверен по референсу (rAF, 600мс, хвост 60мс,
   cubic-bezier(.35,0,.15,1), два блоба шириной в ячейку под gooey `me-tab-goo`,
   фильтр всегда включён). После объединения он заработает БЕЗ mount-хака —
   убрать `window.__meTabPrev` и анимировать по смене пропа `active`.
5. Удалить дубль индикатора из `AChat` (`me-chat-goo`, `tabInd2`, `kfTab2`).
