# MAYA_WORKSPACE

Локальный мета-репозиторий для порядка на рабочем столе и навигации по проектам MAYA / Мужская Эстетика.

Этот репозиторий не двигает существующие проекты и не ломает пути Xcode/деплоя. Он хранит карту, правила и инструкции, а сами рабочие проекты остаются на своих местах.

## Правило порядка

Не переносить существующие папки проектов без отдельного плана миграции. Для полного порядка на Desktop сначала надо:

1. Составить список активных проектов и архивов.
2. Отметить, какие пути используются в Xcode, Git, deploy-командах и скриптах.
3. Создать новую структуру.
4. Перенести только после проверки, либо оставить совместимые symlink-пути.
