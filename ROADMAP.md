## P0 — Безопасность (СРОЧНО, до любой новой фичи)

> Детали находок — в [PROJECT_MEMORY.md](PROJECT_MEMORY.md) §5. Все секреты считать скомпрометированными.

- [ ] **Завести git + `.gitignore`** для всего дерева. Игнорировать: `config.py`, `*.pem`, `*.db`, `*.log`, `*.bak*`, `*.sesstoken`, `*.yclientsms`, `*.keystore`, `__pycache__/`, `.DS_Store`, `signing-key-info.txt`, `secret_key.txt`.
- [ ] **Вынести все ключи в переменные окружения / секрет-стор**, убрать значения из кода.
- [ ] **Ротировать:** Telegram (оба бота), Claude, OpenAI, YClients partner+user, VK secure+access, Publer, YooKassa secret+provider, WEBHOOK_SECRET, CRM API_TOKEN, VAPID-пару.
- [ ] **`PII_ENCRYPTION_KEY`** ротировать ТОЛЬКО с миграцией зашифрованных данных (иначе ПД станут нечитаемыми).
- [ ] **Удалить из веб-рута Beget**: `api-proxy.php.bak.sesstoken`, `*.pem`; конфиги вынести выше docroot; расширить `.htaccess` (`bak|sesstoken|yclientsms|py`) или не класть секреты в docroot вовсе.
- [ ] **bot.log:** замаскировать токен в URL (поднять уровень логгера httpx/telegram), очистить/перевыпустить лог.
- [ ] **Keystore:** убрать `signing.keystore` + `signing-key-info.txt` + `secret_key.txt` из синхронизируемых папок; при подтверждённой утечке — сброс upload-ключа в Play App Signing.
- [ ] Использовать **отдельные ключи на приложение** (бот ≠ smm_bot), чтобы ограничить blast radius.
