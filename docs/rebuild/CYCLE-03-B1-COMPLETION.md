## Дедупликация: отпечаток вместо идентификатора

Идентификатора события провайдер **не даёт** ни в одном из трёх известных
форматов вебхука. При этом повторяет доставки — измерено по боевому журналу:
**421 доставка на 148 записей за неделю, до семи повторов одной пары**.

```
dedupFingerprint = sha256(источник | сущность | id | тип | состояние)
```

| Правило | Почему |
|---|---|
| времени в отпечатке нет | иначе повтор того же факта выглядел бы новым фактом |
| порядок ключей и услуг не влияет | иначе тот же факт, собранный другим кодом, был бы «новым» |
| `null` и `undefined` неразличимы | то же самое |
| уникальность **в базе** | множество в памяти не переживает перезапуск |
| уникальность **внутри арендатора** | глобальная позволила бы двум салонам подавлять друг друга |

## Приём и обработка — разные вещи

| Исход | Смысл |
|---|---|
| `persisted` | факт принят |
| `duplicate` | штатное поведение источника, **не ошибка** |
| `pending → processing → processed` | путь обработки |
| `failed` | попытка не удалась, факт остался |
| `dead` | попытки исчерпаны — **видимый** исход вместо тихого вечного повтора |

Провал обработки **не удаляет факт**: это состояние обработки, а не отмена
того, что событие произошло.

Захват — `FOR UPDATE SKIP LOCKED` плюс аренда: два обработчика не возьмут одно
и то же, а упавший не удержит событие навсегда.

## Идентичность визита

**Было:** уникальности по внешнему идентификатору нет вовсе, поиск идёт в
пределах клиента. Два пути приёма создали бы два визита на одну запись CRM.

**Стало:** `@@unique([tenantId, crmProvider, crmExternalId])` — ключ
**квалифицирован провайдером**: число `12345` у YCLIENTS и у Altegio — разные
записи.

🔴 Половина ключа не может быть пустой: это держит CHECK в базе. Без него
внешний идентификатор без провайдера молча отключил бы уникальность ровно для
тех строк, ради которых она вводится.

Событие ссылается на `Appointment.id`; внешний идентификатор живёт в
`sourceRef` как провенанс.
