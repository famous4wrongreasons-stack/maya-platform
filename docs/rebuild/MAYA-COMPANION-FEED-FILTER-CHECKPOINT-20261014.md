## Результат и граница

Существующие фильтры «Все» и «Непрочитанные» перенесены из inline-кнопок
в нижний лист Companion «Ваша лента». Кнопка «Настроить ленту» открывает
нативное модальное окно. Выбранное значение берётся из прежнего runtime view;
выбор вызывает только существующий `WorkspaceReadsPort.filterUnread`.
Повторный выбор того же значения просто закрывает окно.

Фильтр относится только к уже загруженной части ленты. Для ограниченного ответа
явно показаны 50 последних уведомлений. Открытие, выбор и закрытие не отправляют
запросы, не отмечают уведомления прочитанными и не меняют подписки. При загрузке
или отказе источника варианты недоступны. Отметка о прочтении остаётся отдельным
действием с существующим подтверждением результата и authoritative reread.

Окно удерживает фокус; фон неактивен. Escape закрывает только фильтр и возвращает
фокус к его кнопке. Завершение уже начатой отметки о прочтении не забирает фокус
из открытого окна. Потеря сессии удаляет окно и сохранённые строки через прежнего
owner. Новое локальное состояние содержит только признак открытия окна.

Backend, runtime, schema, API, Client Identity, Action Engine, release/entitlement
semantics и HANDOFF не менялись. Нет новых зависимостей, assets или origins.
Изменены только три React source-файла и два carrier test-файла.
