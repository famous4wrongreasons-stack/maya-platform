# Ручные действия перед выпуском

Подготовлено заранее. Production-действия в этом проходе запрещены.

1. Владелец подтверждает доступ к существующей глобальной учётной записи platform_owner. Учётная запись активна; действующей сессии при проверке нет. Логин и создание сессии выполняются только на этапе отдельно разрешённого выпуска. Пароль не присылать в чат.
2. Владелец выбирает один подконтрольный Ed25519 signer: публичный ключ, key ID, fingerprint и соответствующий глобальный User ID. Приватный ключ остаётся вне репозитория и чата. Production trust пока пуст. Второй reviewer и вторая собственная подпись не нужны; отсутствие независимого human review обязательно фиксируется.
3. После нового SHA владелец рассматривает свежие доказательства и отдельно разрешает production execution. Подписывает точные canonical bytes V2 execution authorization: candidate/build/certificate/evidence/profile, один tenant, актуальный CAS, окно не более 24 часов и ответственный за откат. Подпись и платформенная сессия не заменяют друг друга.
4. Для последующей отдельно разрешённой установки владелец подключает и разблокирует свой iPhone. Действующий development profile покрывает это устройство и истекает 5 октября 2026, 08:16:21 UTC. При истечении требуется обновление через реальную Apple-учётную запись. Телефон сейчас отключён; установка не выполнялась.

После отдельного разрешения агент может технически выполнить backup, проверку/установку публичной trust-конфигурации, две сертифицированные миграции, deploy точных артефактов, health checks, canonical login с приватно предоставленными учётными данными, validate/grant/revoke и сборку/установку. Реальные подписи и доступ владельца агент не подменяет. Пока необходимые внешние условия не подтверждены, READY FOR PRODUCTION EXECUTION AUTHORIZATION = NO.
