Нельзя переносить Mac proof как Linux acceptance.

Минимальная допустимая граница продолжения: один явно выбранный и версионно закреплённый локальный OCR executable с квалифицированными ru/en assets, bounded bytes/pixels/pipe output/time/concurrency и zero automatic download/remote fallback на запросе. Сохранить existing authenticated upload, source/actor checks до/после, request-local originals/rows, review_required и неизвестный price_kind, существующий AE downstream. Реальную Linux geometry/engine provenance нельзя маркировать как Vision revision3 только ради прохождения старого DTO: нужен честный finite internal mapping без нового общего capability framework. Выбор package/model assets, их установка/сборка и runtime proof следуют отдельному конкретному execution scope parent; этот read-only отчёт ничего не устанавливает и не разрешает production deployment.
