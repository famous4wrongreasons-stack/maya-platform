# Fixed first-phone evidence decomposition

Implements the already approved [Option B](../../MAYA-FIRST-PHONE-SCOPE-DECISION-20261015.md),
item 6. This is evidence representation in the existing AR-1, not a further
scope decision, another release engine, or permission to deploy/grant.

The preserved `cfea53a8` implementation required whole-row L-T for all eight
shared duties. That cannot truthfully describe the restricted registry: the
only actual approval decision templates are the six expressly excluded price
and goods templates. B35's AE owner/allowlist remains present, but its generic
widget approval carrier is still unavailable. An ordinary booking record
cannot stand as evidence of an approval decision. Previous receipts remain
historical; their L-T requirement is superseded by this decomposition.

## Exact representation

All 165 global IDs remain. G6-6 and G13-R8 remain STOP. The eight shared rows
have `state: SCOPED` **only in the new fixed profile certificate**. This says
that their remaining and excluded branches have distinct mandatory evidence;
it does not promote their global status to L, L-T or U. The original profile
and full-contract parser still refuse this representation.

Each scoped row requires:

- The exact `FP-<global-id>` remainder, with its own evidence digest.
- G7-FR6d: L proof of the existing non-MONEY booking path, from a real
  production mint through HTTP and the compiled binary. This proves only
  that remainder, never the globally available F32a/F32b exceptions.
- The seven approval remainders: U with all four existing OD-3 duties.
  The executable census checks actual registries, generic template refusal,
  and the continued presence of the B35 authority owner. This is an existing
  unavailable carrier, not another excluded operation. Adding any actual
  approval carrier fails the census and requires new qualification.
- Separate refusal and mechanism digests. G7's remaining MONEY/PAYMENT_HANDOFF
  refusals and Gate 11/13 owners retain their mechanism tests and mutations.
- The two fixed excluded-source proof sets, each with decision, absence,
  refusal and mechanism digests. These remain compulsory on every row.
- A digest binding all those components, plus the existing complete matrix,
  candidate, registry, profile, certificate and authorization bindings.

No whole shared row can be replaced with U/STOP/L/L-T. No other clause can
become SCOPED. This re-pins only the additional first-phone profile digest;
the original no-HANDOFF manifest/digest, source registries, runtime, authority
and business operation implementations are unchanged by this correction.

## Existing collector, separate branch identifiers

`BRANCH-EVIDENCE.json` is the finite input map. The helper
`maya-saas-backend/scripts/widgets-first-phone-evidence-inputs.mjs` creates
temporary inventory/audit/U-map inputs for the **existing unchanged** strict
collector. They preserve the 165 global rows and add eight distinct `FP-`
branch IDs. They do not update the historical global audit or issue a certificate.

The existing WR HTTP/BIN source proof emits `FP-G7-FR6d` only when
`WIDGETS_EVIDENCE_PROFILE=closed-input.no-handoff.no-price-goods@1` is selected.
The new BUILD/RI ledger offers the seven unavailable approval remainders under
that same explicit evidence setting. There is no fabricated production mint,
model replacement or second evidence writer. The unchanged global collector
refuses these branch identifiers, so they cannot satisfy whole global clauses.

Collector acceptance verifies provenance and format only. Full fresh mechanism
mutations, source isolation, CI, carrier/FBE2E and release admission remain
mandatory on a committed candidate. The enlarged corpus contains 557 declarations
in the existing 48 batteries/69 jobs. Declared counts are not executed results.
