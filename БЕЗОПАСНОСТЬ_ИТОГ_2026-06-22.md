## 🔧 ПОДГОТОВЛЕНО, нужно применить на сервере (в чате бота / с доступом к VPS)
Это самое важное по безопасности, но чинится **на сервере бота**, не с этого чата.
Точные места и патчи — в детальных отчётах. Кратко:

- **Журнал мастера — доступ к чужим записям** (главное!): сейчас любой привязанный мастер может по номеру записи смотреть/отменять/переносить/«оплачивать»/править **любую** запись салона и видеть данные любого клиента. → добавить проверку владельца записи.
- **Порт бота (8080) открыт по незащищённому HTTP** — через него идут перс. данные и платежи. → закрыть фаерволом / завести за HTTPS, слушать только локально.
- **4-значный код входа по SMS подбирается** — нет ограничения попыток. → лимиты + длиннее код.
- **Перс. данные клиентов частично утекают в ИИ** (советы мастерам) — обезличивание неполное. → расширить очистку.
- **Анонимная запись на любое время** через `api-proxy.php` (тихий обход проверки рабочих часов). → убрать обход (по твоему решению логику записи пока не трогал).
- Гонки при списании баллов/сертификатов, лимиты на ИИ/голос, и др. — см. отчёты.
