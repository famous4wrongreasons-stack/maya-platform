## 1. Суть видения

Не «улучшенный бот», а **вертикальный AI-агент — операционный мозг салона**.

**Один мозг — много лиц.** MAYA — это единый «мозг», а Telegram / PWA-чат / телефон / экран мастера — это **каналы** (лица). Сегодня «Антон» уже живёт в двух каналах (TG + PWA-чат, один мозг) — это база, которую надо расширять знаниями и полномочиями, а не переписывать.

### 4 роли (персоны) MAYA

| Роль | Для кого | Что делает | Уровень доверия |
|---|---|---|---|
| **Консьерж / администратор** | клиент | записать, перенести, ответить, посоветовать, удержать, принять звонок | write — через ворота подтверждения |
| **Наставник** | мастер | досье клиента, как стричь, техники, апсейл-подсказка | read + база знаний |
| **Замдиректор** | владелец | аналитика по запросу, состояние бизнеса, ЗП, расход, аномалии | read-only — автономно |
| **Голос** | клиент по телефону | то же, что консьерж, но через телефонию | write — через ворота |

## 2. Прецеденты (из исследования, 2026-06)

- **Голос на звонках — зрелая отдельная категория.** Bolna, AgentZap, My AI Front Desk, BookingBee, PolyAI, Slang.ai: приём звонков 24/7, проверка слотов, бронь, SMS. Боль: салоны пропускают **до 35%** входящих звонков; **46–50%** записей — вне рабочих часов. Ценник массовых решений $49–499/мес vs $2 500+ за живого ресепшиониста. Вывод: голос реалистичен, но это **отдельный модуль**.
- **«AI-сотрудник» = архитектура, не магия.** В проде агент — распределённая система, где LLM = планировщик. Три кита: reasoning-цикл + память + инструменты, плюс error-handling/валидация/retry.
- **Деньги и необратимое — через человека в цикле.** Модель предлагает → человек подтверждает write/финансы; read-only автономно. Ворота на всё → накопить статистику → снимать ворота с низкорисковых при 95%+ корректности.
- **Голос на русском в РФ — отдельный стек из-за геоблока Claude.** Телефония Voximplant (SIP) + STT/TTS Yandex SpeechKit + мозг через прокси. Yandex меняет формат realtime-агентов с 12.05.2026.

## 3. Поправки (обязательно учесть)

1. **Безопасность — фундамент, а не техдолг.** AI-директор имеет доступ ко ВСЕМУ (деньги, ПД, ЗП). Цена ошибки растёт на порядок. P0 из ROADMAP (git, ротация ключей, секреты в env) — **вход в проект**, до расширения полномочий MAYA.
2. **Read ≠ Write.** Аналитика/отчёты/расчёт ЗП-как-цифры — автономно. Оплата/отмена/рассылка/выплата — через ворота подтверждения.
3. **Привычки клиента — память, не нарушение 152-ФЗ.** «Любит фейд, кофе без сахара» — это профиль предпочтений (привязан к internal id), не ПД. Расширение существующего модуля `memory` + `anonymizer`, контур «ПД не в LLM» сохраняется.
4. **«Как стричь» — нужна база знаний (RAG).** LLM из коробки галлюцинирует про стрижки. Нужен слой знаний (стандарты/техники/регламенты) с retrieval. Новый компонент.
5. **Голос — последняя фаза.** Сначала «дешёвый голос»: голосовые в TG (есть `handle_voice`) + «пропущенный звонок → MAYA перезванивает». Потом — телефония.

## 4. Архитектурный сдвиг

AI-амбиция совпадает с техдолгом (ROADMAP P2) — это **один** проект, не два.

| Сейчас | Нужно |
|---|---|
| 2 монолита | **Agent Core** — единое ядро, общее для каналов |
| 20 tools хардкодом | **Реестр инструментов** с правами read / write(ворота) |
| константы размазаны | **Единый каталог** продуктов/цен/правил/ЗП |
| память без ПД (есть) | **+ слой предпочтений** клиента |
| — | **База знаний (RAG)** для наставника |
| — | **Слой evals** (менять промпт, не ломая запись/деньги) |
| — | **Guardrails** — ворота на write/деньги |

**Уже есть (~60% пути):** один мозг TG+PWA, 20 tools, интеграция YClients, память без ПД, обезличивание, биллинг токенов, CutMatch, дневной отчёт, GOD-режим.

## 5. Дорожная карта (статус на 2026-06-17)

- **Фаза 0 — Фундамент (блокер).** 🟡 Частично. Единый каталог констант начат (`business_rules.py`). `.gitignore` готов (покрывает config.py/tg-config/keystore/.env/*.db/*.bak). ⚠️ ТРЕБУЕТ СТАСА: ротация боевых ключей (нельзя автономно — уронит прод и нужны дашборды YooKassa/YClients/Telegram), `git init`+первый коммит ПОСЛЕ ротации. Зазоры .gitignore: `api-proxy.php` (плейнтекст-токены — нужен вынос секретов, не gitignore) и `conversations.json` (история диалогов) — добавить перед git init.
- **Фаза 1 — Замдиректор.** ✅ ЗАДЕПЛОЕНО + e2e на VPS. `get_business_report` (read-only): выручка нал/карта, визиты, средний чек, ЗП по мастерам, динамика (рост/спад), топ-услуги. Ворота `is_admin`. `business_rules.py` + `analytics.py`.
- **Фаза 2 — Наставник.** ✅ Код готов + локальные тесты, 🟡 деплой в очереди (ждёт «заливай»). Инструменты в `claude_ai.py`: `get_client_dossier` (мастеру: история+любимые услуги+цикл+привычки, без телефона), `remember_client_preference` (обезличенный профиль, таблица `client_preferences`), `barber_knowledge` (RAG-ретрив из `barber_knowledge.md` — ЧЕРНОВИК, Стас дополняет стандартами салона; MAYA не выдумывает технику). ⚠️ ТРЕБУЕТ СТАСА: наполнить `barber_knowledge.md` реальными стандартами/техниками.
- **Фаза 3 — Консьерж.** 🟡 Стартовый инкремент: `memory.build_context` подмешивает обезличенные привычки клиента → MAYA узнаёт вернувшегося. Деплой в той же очереди. Проактивность (реактивация/ДР/цикл) уже жила раньше. Ворота подтверждения на write — следующий шаг.
- **Фаза 4 — Голос.** 🟡 «Дешёвый голос» готов как опциональный модуль `voice.py` (OpenAI TTS через существующий прокси, выключен флагом `VOICE_REPLIES_ENABLED`, не вшит в bot.py). STT входящего голоса уже работает (Google, `transcribe_voice`). ⚠️ ТРЕБУЕТ СТАСА: решение включать ли голосовые ответы клиентам; для НАСТОЯЩЕЙ телефонии (приём звонков) — открыть/оплатить Voximplant (SIP+номер) + Yandex SpeechKit, строить на новом realtime-API (изменился с 12.05.2026).
